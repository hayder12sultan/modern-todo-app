# Modern To-Do Application

A beautiful, mobile-first task management application with full CRUD functionality, built with pure HTML, CSS, and JavaScript.


## ✨ Features

- Create, Read, Update, Delete tasks
- Mark tasks as complete/incomplete
- History tracking of completed tasks
- Local storage persistence
- Mobile-first responsive design
- Clean, modern UI
- Real-time task statistics
- Toast notifications for user actions

## 🛠️ Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Flexbox, Grid, Animations, Media Queries
- **Vanilla JavaScript (ES6+)** - Pure JS, no frameworks
- **LocalStorage API** - Data persistence

## 📱 How to Use

1. **Add tasks** - Type in the input field and click Add or press Enter
2. **Complete tasks** - Click the checkbox to mark as done
3. **Edit tasks** - Click the Edit button and modify the title
4. **Delete tasks** - Click Delete and confirm removal
5. **Filter tasks** - Use tabs to view All, Active, Completed, or History
6. **Clear completed** - Use the button to remove all finished tasks
